# flashtrace

Lightning-fast, reference-based requirement tracing between Markdown
specifications and source code.

This package installs the `flashtrace` command as a prebuilt native binary:
the matching `@flashtrace/<platform>-<arch>` package arrives through
`optionalDependencies` and a small launcher hands the process over to it.

Documentation, examples and sources: <https://github.com/flashtrace/flashtrace>
